The magenta backgrounds are taken off by the cut-out. This was checked on the front pictures and on a story-board sheet: no
magenta is left, and the faces are found.

The first three story-board sheets show the girls with brown hair as well as black. The colour check reads those
figures as different characters, so they serve as references only.

The ceiling fan and the wall clock are in the room pictures; the fan and clock sheet and the close room views can be
given to each of them under Studio → 7. Backgrounds, or under the film's waiting card, which has a button for each
picture it waits on and "Continue — the studio draws what has no picture".
